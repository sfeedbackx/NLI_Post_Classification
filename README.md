# NLI_Post_Classification
classifying post based on frames and Critical Metaphor Analysis using Natural Language Inference 

# set up
## Linux
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter-lab
```
## Windows
```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
jupyter-lab
```

# Cuda
Make sure CUDA is installed so we can use the GPU for parallel computing (for model NLI) otherwise it will use ur CPU
